# Spacing

This document defines the spacing scale used across the project.

## Spacing tokens

```css
:root {
  --spacing-zero: 0px;
  --spacing-xxs: 2px;
  --spacing-xs: 4px;
  --spacing-s: 8px;
  --spacing-m: 16px;
  --spacing-l: 32px;
  --spacing-xl: 64px;
}
```

## Usage guidelines

- Use `--spacing-zero` for no spacing or reset cases.
- Use `--spacing-xxs` and `--spacing-xs` for compact spacing adjustments.
- Use `--spacing-s` and `--spacing-m` for standard component spacing.
- Use `--spacing-l` and `--spacing-xl` for larger layout separation.

## Scale summary

- `0px` — zero
- `2px` — xxs
- `4px` — xs
- `8px` — s
- `16px` — m
- `32px` — l
- `64px` — xl
